# はなだトリミング (hanada-trimming)

GitHub Pages上で動作する、IRIAM（イリアム）のアイコンとヘッダー画像の位置をぴったり連結するためのトリミングツールです。

## 概要
選択した画像をキャンバス上でドラッグ移動や拡大縮小（ホイール・ピンチ操作）しながら直感的に位置調整し、IRIAMの仕様に合わせたヘッダー画像およびアイコン画像を個別に切り出して保存できます。
PWAに対応しているため、スマホのホーム画面に追加してアプリ感覚で利用可能です。

## フォルダ構成
```
hanada-trimming/
├── index.html          # メインページ・ UI・ロジック
├── manifest.json       # PWA設定ファイル
├── sw.js               # Service Worker（オフラインキャッシュ対応）
├── Kame-Shiro-Noir.jpg # ファビコン・OGP・アイコン用画像
└── README.md           # 本ファイル
```

## 機能・特徴
1. **IRIAM規格への自動最適化**
   - ヘッダー（1125×480）とアイコン（513×513）の位置関係をリアルタイムでプレビュー表示。
   - 円形枠からの食い込みを防ぐクランプ処理を実装。
2. **PWA（Progressive Web App）対応**
   - スマホやPCのホーム画面にインストールして全画面で起動可能。
   - Service Workerによるオフライン表示サポート。
3. **レスポンシブ & OGP対応**
   - PC・スマートフォンどちらの画面サイズにも最適化。
